# Laser Price PRO

Калькулятор стоимости работ и готовых изделий для CO₂ лазерных станков.

## Платформы
- Web/PWA: браузер телефона и компьютера.
- Android: APK через GitHub Actions (Capacitor).

## Настройки проекта
- Станки: профили 40–60 Вт и 80–100 Вт, с возможностью добавления своих.
- Валюта: RUB.
- Ввод: ручной расчёт и импорт DXF (анализ геометрии и оценка времени по выбранному технологическому профилю).

## Сборка
GitHub Actions собирает веб-версию и Android APK. Для локальной разработки требуется Node.js; Android Studio пользователю не нужна.

## Статус
Начальная структура проекта создаётся. Расчётные значения машинного времени являются оценкой и должны калиброваться под конкретный станок, материал, мощность и режим.
